# PVE-04 / OptiPlex 3080 baseline audit - 6 October 2026

## Purpose

This session established a clean technical baseline for the fourth Proxmox node, `pve3080b`, before assigning production-like lab workloads.

## System summary

- Hostname: `pve3080b`
- Proxmox VE: 9.2.21
- Running kernel: `7.0.14-20-pve`
- CPU: Intel Core i5-10500T
- CPU topology: 6 cores / 12 threads
- RAM: 8 GB DDR4-2666 currently installed
- Storage: Samsung MZ7LN256HCHP 256 GB SATA SSD
- Management address: `192.168.1.167:8006`
- Current role: clean lab node reserved for testing, security and automation work

## Audit scope

The audit covered:

- Proxmox version and running kernel
- CPU topology and temperatures
- memory and swap usage
- DIMM population
- LVM and Proxmox storage
- filesystem usage and inode usage
- SMART health
- Ethernet link state
- LAN, Internet and DNS connectivity
- hostname and FQDN resolution
- timezone and NTP synchronisation
- failed systemd services
- cluster state
- firewall state
- backup jobs and cron
- current-boot journal messages
- PCI devices
- BIOS/firmware information

## CPU and memory

The i5-10500T was confirmed as a 6-core / 12-thread processor.

CPU temperatures were approximately 30-33°C during the audit.

The node currently has one 8 GB DDR4-2666 module installed, leaving the second memory slot available. A future upgrade to 16 GB is planned.

Swap was present but unused during the audit.

## Storage

The 256 GB SATA SSD uses the standard Proxmox layout:

- EFI system partition
- Proxmox swap
- `pve-root` EXT4 logical volume
- `pve-data` LVM-thin pool

Proxmox storage:

- `local`
- `local-lvm`

No VMs or LXC containers were present.

SMART reported an overall health status of PASSED. The short self-test completed without error. No reallocated or uncorrectable sectors were reported.

The drive has substantial historical power-on time, so continued SMART monitoring remains appropriate for a learning lab.

## Networking

The node uses the physical interface `nic0` through the Proxmox bridge `vmbr0`.

The management address is:

`192.168.1.167/24`

Gateway and DNS:

`192.168.1.254`

The Ethernet link was verified at 1 Gb/s full duplex.

Tests confirmed:

- LAN gateway reachability
- Internet connectivity
- DNS resolution

## System services

The system showed no failed systemd services.

The node is intentionally standalone and has no Corosync cluster configuration.

No Proxmox backup jobs or root cron jobs were configured.

A repeated Postfix warning about a missing `/etc/aliases.db` database was corrected safely by rebuilding the aliases database with `newaliases`. No new priority-3 occurrences appeared after the fix.

## BIOS and firmware investigation

The installed Dell system firmware was identified as version 1.1.0.

`fwupd` and `udisks2` were installed to inspect available firmware metadata. The EFI System Partition was verified and `fwupd` was configured to recognise the mounted ESP.

LVFS reported a newer OptiPlex 3080 firmware version as available.

The Dell firmware attribute interface also confirmed that an administrator BIOS password is enabled. Because firmware flashing can interact with BIOS security state, no BIOS update was attempted during this session.

This was intentionally treated as a separate future maintenance task rather than risking a stable Proxmox installation.

## Result

`pve3080b` is healthy enough for continued lab use and is now documented as a clean testing node.
